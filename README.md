## 사건

1947년 로스앤젤레스. LAPD 형사는 호텔 버질 942호의 투숙객 **아이리스 밴스**를 찾기 위해
로비에 들어선다. 호텔은 실종도, 9층의 단수도 신고하지 않았다. 야간 프런트 **마를로 다이치**는
그녀가 이미 호텔을 떠났다고 주장하지만, 숙박부와 객실 기록은 다른 이야기를 가리킨다.

이 작품의 인물, 사건, 호텔은 모두 허구이며 실존 인물·사건·업체와 무관하다.

## 플레이 흐름

1. **로비를 조사한다.**

   - 숙박부와 호텔 곳곳을 살펴 단서와 관찰 기록을 모은다.
   - 수집한 증거는 수사노트에서 다시 확인할 수 있다.

2. **다이치의 진술을 판단한다.**

   - 각 진술에 `진실`, `의심`, `거짓` 중 하나로 답한다.
   - `거짓`을 선택했다면 수사노트에서 근거가 될 증거를 직접 고른다.

3. **판단의 결과를 감수한다.**

   - 한 번 내린 판정은 되돌릴 수 없다.
   - 잘못된 증거를 제시하면 해당 진술과 그 진술이 열어 줄 정보가 이번 회차에서 닫힌다.
   - 오답이 나와도 게임은 멈추지 않고, 수사는 그 결과를 안고 계속된다.

4. **9층과 942호를 수색한다.**

   - 심문을 마치면 엘리베이터 격자문을 열고 9층으로 이동한다.
   - 942호에서 사건을 다음 단계로 이끄는 물증을 확보하면 현재 에피소드가 끝난다.

## 조작 방법

| 입력 | 동작 |
|---|---|
| 마우스 클릭 / 이동 | 포인터 잠금 / 시선 이동 |
| `W` `A` `S` `D` | 이동 |
| `Shift` | 달리기 |
| `E` | 조사, 수집, 대화, 상호작용 |
| `Tab` | 수사노트 열기 / 닫기 |
| `Esc` | 열린 화면 닫기 / 일시정지와 설정 |
| `1` `2` `3` 또는 쪽지 클릭 | 심문 중 진실 / 의심 / 거짓 선택 |
| 방향키 또는 증거 클릭 | 제시할 증거 이동 / 선택 |
| `Enter` | 선택한 증거 제시 |

성능이 부족하면 `Esc → 설정 → 품질`에서 `medium` 또는 `low`를 선택할 수 있다.

## 핵심 특징

- **증거 중심의 비가역 심문**

  - 단순 대화 선택지가 아니라, 진술과 물증의 관계를 플레이어가 직접 판단한다.
  - 실패를 재시도 화면으로 되돌리지 않고 사건의 상태로 남긴다.

- **1947년의 물성을 유지하는 인터페이스**

  - 선택지는 카운터 위 종이 쪽지로, 수사 기록은 LAPD 서류철 형태로 표현한다.
  - 현대적인 HUD를 줄이고 화면 안 소품과 문서가 정보를 전달하도록 설계했다.

- **마리오네트 누아르 연출**

  - 인물은 도자기 얼굴과 목제 관절을 가진 마리오네트로 표현한다.
  - 시선, 손, 어깨와 자세 변화가 심문 중 불안과 거짓의 단서가 된다.

- **절차 생성 3D 월드**

  - 텍스처, PBR 재질, 지오메트리, 환경광과 대부분의 오디오를 코드로 생성한다.
  - 외부 게임 에셋은 AI 생성 타이틀 배경 1장과 CC BY 4.0 음악 5곡뿐이다.

- **자체 렌더링 파이프라인**

  - Three.js 위에 TAA, GTAO, SSR, 볼류메트릭, 블룸, DOF와 모션 블러를 직접 구성했다.
  - 시드 난수와 엔진 시계를 사용해 QA 장면을 결정론적으로 재현한다.

- **기계 검증 가능한 추리 구조**

  - 사건 사실 그래프, 심문 상태기계, 증거 소각 규칙과 플레이 경로를 자동 검사한다.
  - 고정 카메라 스크린샷과 픽셀 비교로 시각 회귀를 추적한다.

## 로컬에서 실행하기

### 요구 사항

- Node.js `20.19+` 또는 `22.12+`
- npm

### 개발 서버

```bash
git clone https://github.com/bluetop1102/virgil-1947.git
cd virgil-1947
npm ci
npm run dev
```

브라우저에서 <http://127.0.0.1:5173>을 연다.

### 빌드와 검증

```bash
npm run build                         # 일반 프로덕션 빌드
npm run build:pages                   # GitHub Pages용 상대 경로 빌드
node tools/factcheck.mjs              # 사건 사실 그래프 검사
node tools/test-interrogation.mjs     # 심문 상태기계 검사
node tools/playthrough.mjs --fast --act 1  # 1막 자동 완주 검사
```

결정론적 QA 스크린샷은 다음과 같이 촬영한다.

```bash
npm run shot                          # 전체 샷
npm run shot -- lobby-wide            # 단일 샷
```

## 프로젝트 구조

- `src/core/`

  - 엔진, 이벤트 버스, 상태 저장소, 품질 설정과 결정론적 시간

- `src/render/`

  - 렌더 타깃과 포스트프로세싱 파이프라인

- `src/materials/` · `src/world/`

  - 절차 재질, 지오메트리 키트, 소품, 조명과 플레이 공간

- `src/narrative/` · `src/gameplay/`

  - 대사, 심문 상태기계, 증거 그래프, 이동과 상호작용

- `src/chars/` · `src/ui/` · `src/audio/`

  - 마리오네트 연기, 수사노트와 화면 연출, 공간 음향

- `tools/`

  - 사실 검사, 계약 린트, 자동 완주, 성능 측정과 스크린샷 회귀 도구

- `docs/`

  - 설계 계약, 사건 사양, 품질 루브릭, 검증 기록과 제출 문서
