## 무엇을 하는 게임인가

942호 손님이 이틀째 보이지 않는다. 프런트에서 단서를 모으고, 야간 프런트 다이치를
심문한다 — 진술마다 **진실 / 의심 / 거짓**을 고르고, 거짓이라면 증거를 직접 내민다.

> **내민 증거는 무르지 못한다. 닫힌 진술은 다시 열리지 않는다. 수사는 계속된다.**

오답은 그 진술과 그 진술이 물고 있던 하류 정보를 영구히 태운다. 심문을 끝내면
격자문이 열리고, 9층 복도와 942호 — 실종자의 방 — 가 기다린다.

- **절차 생성**: 텍스처(GPU 셰이더)·지오메트리(코드 생성 소품 40종)·환경광(IBL)·
  오디오(리버브 IR·효과음·룸톤 전부 WebAudio 합성). 외부 에셋은
  **AI 생성 타이틀 배경 1장과 CC BY 4.0 음원**(Kevin MacLeod, incompetech.com)뿐이다 —
  전수 목록·라이선스 전문·후처리 실측은 [docs/credits.md](docs/credits.md).
- **결정론**: `Math.random()`·`Date.now()` 금지 계약. 시드 난수와 엔진 시계만 쓴다.
- **기계 검증**: 사실 그래프 검사기(factcheck) · 심문 상태기계 배터리 112건 ·
  소각 직렬화 9건 · 완주 봇 · 계약 린트 · 결정론적 스크린샷 회귀 게이트.
