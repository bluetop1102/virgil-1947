## 고정 조건 (교란 차단 — 리뷰 §1·§3 반영)

- **base commit 고정**: 전 라운드(재기준선 포함)는 동일 base commit 의 클론에서 실행한다.
  base = 이 파일 v2 를 커밋한 시점의 본체 HEAD (라운드 기록표에 해시 기입). 본체가
  전진해도 실험 클론은 base 를 유지한다.
- **rig.js 외 변경 0**: 회수 시 `git status`/diff 로 산출 외 파일 무변경을 확인한다.
  다르면 라운드 무효.
- **프레임 고정**: 채점 대상은 A1 표준 프레임(interrogation-deitch, 하네스 카메라 —
  에이전트 소유 밖) + 접지 보조 앵글 1장. 인물 배치(카메라 대비 거리·방향)는 라운드 0 과
  동일해야 한다 — 배치 이동으로 프레이밍을 바꾸는 것은 게이밍으로 간주, 라운드 무효.
- **회수 측 재촬영**: 채점 샷은 에이전트 제출본이 아니라 **회수 측이 클론에서 재촬영**한
  것만 쓴다(동일 하네스·동일 프리셋·2560×1440).
- **시험 적응 감사**: 회수 시 rig.js 에서 샷 이름·씬 ID·qa 상태 분기로 품질을 조건 분기하는
  코드를 grep 검사한다. 발견 시 라운드 무효(게이밍).

   않는다(격차 분류 시 ② 판단 근거).
2. **블라인드 채점 (회수 측, 판정 정본)** — grader-rig.md v2 를 제작 맥락 없는 **별도
   에이전트 3개에 독립 투입**(회차·제작 주체·이전 점수 비공개). 입력: 재촬영 표준
   프레임 + 접지 보조 앵글 + 스타일 정본 참조. **항목별 중앙값**이 라운드 점수다.
   항목 점수 범위(최대-최소)가 1점 초과면 판정 보류 — 해당 항목만 재채점 1회 후 중앙값.
   채점자 모델·설정을 기록표에 남긴다.

## 라운드 판정 순서 (리뷰 §4 반영 — 이 순서대로만)

1. **무효 검사**: unobservable 항목 존재(보충 촬영으로 해소 불가) · rig.js 외 변경 ·
   배치 이동 · 시험 적응 검출 → **라운드 무효**(유효 발주 회차로 세지 않음, 재촬영·재발주).
2. **통과 검사**: 중앙값 기준 통과선 도달 → **실험 성공, 즉시 종료**.
3. **정체 검사**: 총점(C-G 4항목 중앙값 합)을 **역대 최고 라운드와 비교**. 개선 = 총점
   상승 **그리고** 실격·style-fit 악화 없음. 총점 변화가 그 라운드 채점 분산(3회 범위 최대값)
   이하면 **정체**. 정체 2회 연속 → 종결, "이 구성에서 관측된 미달"로 기록.
4. **상한 검사**: 유효 발주 4회 소진 → 종결.
