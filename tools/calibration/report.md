# 교차 에이전트 캘리브레이션 — 리포트

> 실행 규약: [protocol.md](protocol.md). 이 리포트가 **"위임 개시 가능" 판정의 근거**다.
> 채워지지 않은 표는 판정 근거가 아니다 — 미실행은 미실행으로 남긴다.

**상태: 미실행 (사용자 승인 대기).** 외부 에이전트 실행은 토큰 실비이므로 승인 전에 돌리지 않는다.

---

## 0. 선행 시도 기록 — 무질문 게이트 1회 (2026-08-06)

캘리브레이션과 같은 측정 장치(패킷 1장만 주고 신선한 에이전트 투입)를 내부 서브에이전트로
먼저 돌렸다. 외부 비용이 들지 않는 예비 실행이었다.

| 항목 | 값 |
|---|---|
| 대상 | `T-P0-01` (기계형 파일럿과 동일 티켓) |
| 투입 | 격리 워크트리 · 소지품 `packets/PACKET-T-P0-01.md` 1장 · 문서 열람 금지 |
| 결과 | **미완 — 세션 토큰 한도로 조기 종료.** 패킷 완독 후 코드 스캔 단계에서 중단 |
| 얻은 것 | 패킷을 읽고 작업에 착수하는 데까지는 질문·이탈 0. 그 이상은 측정 못 함 |

측정값이 없으므로 **게이트 통과로 치지 않는다.** 한도 회복 후 재실행 대상이며,
그때는 캘리브레이션 ①과 같은 회차로 묶어 돌린다(같은 티켓·같은 조건이라 중복 비용이다).

한도에 걸린 것 자체가 자원 조항의 실사례다 — 이후 이 세션은 팬아웃을 접고 직렬로 전환했다.

### 대체 측정 — 기계적 자기완결 감사 (실행함)

사람 판정 게이트를 대신하지는 못하지만, "패킷을 읽다가 밖으로 나가야 하는 지점"은 기계로 셀 수 있다.

```
node tools/packet-gen.mjs --audit
```

| 시점 | 잔여 § 좌표 |
|---|---|
| 폐포 도입 전 | 202건 (15장 합계) |
| 폐포 도입 후 | **0건 (15장 전부)** |

즉 지금의 패킷은 **자기가 인용한 계약이 가리키는 절까지 전부 안에 들고 있다.**
이 상태에서 사람 게이트를 돌려야 "질문이 나오면 패킷 결함"이라는 판정이 성립한다.

## 3. 패킷 결함 역반영 목록 — **이 리포트의 본체**

에이전트가 질문했거나 이탈한 지점마다 1행. 결함은 에이전트가 아니라 패킷에 있다.

| # | 어느 패킷·절 | 무엇이 불충분했나 | 무엇을 고쳤나 (매니페스트/생성기) | 재생성·재확인 |
|---|---|---|---|---|
| — | | | | |

**규칙**: 지시서를 손으로 고치지 않는다. `data/manifest/*.json` 또는 `tools/packet-gen.mjs` 를
고치고 `node tools/packet-gen.mjs --all` 로 다시 찍은 뒤 `--audit` 잔여 0 을 재확인한다.
