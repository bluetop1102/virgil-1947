## 3. 작업 (우선순위 순 — 21:00까지 P0 둘이 안 서면 P1을 버려라)

### P0-1. 푸시인 램프 회피 [1.5h]
푸시인 목표점을 램프 축에서 15~20° 비켜 잡거나 푸시 사거리를 당겨라. **어느 진입 각에서도**
얼굴·양손이 프레임에 남아야 한다 — 진입 각을 카메라가 흡수해야지, 플레이어 위치에 맡기면
1차·2차처럼 복불복이 된다. 검증 동선은 §0-6 재현 각(데스크 정면) 그대로 프로브가 걷는다.

### P0-2. 리버스 샷 오버숄더 [1.5h]
판정 반응·증거 제시 컷에 다이치 어깨/데스크 모서리를 전경으로 물려라. 형사 아바타 단독
프레임이 심문 공간을 컷마다 리셋시키는 것이 문제다.

### P1-3. 첫 목표 독백 [30분]
인트로 이양 직후 형사 독백 자막 1줄 — 예: "프런트부터다. 숙박부를 봐야겠다." (STORY 톤 준수,
정확한 문장은 네가 다듬어라). 목표 제시와 첫 상호작용 유도를 한 줄이 겸한다. J1·J5 동시 기여.

### P1-4. 텔 진폭·배경 인형 [1h]
거짓 텔(시선 회피·손 만지작)의 진폭을 한 단계 올리고, 배경 인형 3인에 idle 호흡·체중 이동
미세 모션을 넣어라(`chars/rig.js` — 이미 game:pause를 듣는 구조가 있다).

## 4. 검증 — 이중

**(a) 기계 프로브.**
```bash
npx vite --port 5712 &
PROBE_URL=http://127.0.0.1:5712/ PROBE_OUT=shots/judge-sb node tools/judge-probes/probe-tell.mjs
node tools/test-interrogation.mjs   # 심문 배터리 — 깨뜨리면 실격
```
probe-tell은 §0-6 재현 각으로 걸어서 푸시인 텔 3프레임(`tell-01~03`)·리버스 2프레임
(`tell-04~05`)·이양 독백(`tell-00`)을 만든다. 상태 전이·독백 검출·콘솔 0이 기계 판정이다.

**(b) 블라인드 비전 채점 — 이것이 완료 조건이다.** 구현 내용을 모르는 서브에이전트를 새로
띄워 **프레임 5장만 주고** 이렇게만 물어라(무엇을 고쳤는지 말하지 마라 — 유도 심문 금지):
> "각 프레임에서 ①인물의 얼굴이 보이는가 ②두 손이 보이는가 ③가리는 물체가 있다면
> 무엇인가. (tell-04·05는) ④프레임 안에 보이는 인물과 전경 물체를 전부 나열하라."
PASS 기준: tell-01~03 **3장 전부** 얼굴+양손 가시 · tell-04~05에서 다이치의 어깨 또는
데스크가 전경으로 언급됨. FAIL이면 고치고 프로브부터 다시. 답변 원문을 완료 보고에 인용한다.
