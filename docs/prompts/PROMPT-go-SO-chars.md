## 2. 작업 (우선순위 — 눈이 첫째다)

### P0-1. 눈 [2.5h] — J3의 심장
칠한 구 → **유리 눈**: 각막 스펙큘러 캐치라이트(램프 방향 반응) · 홍채 음영 층 ·
공막-홍채 경계. 목표는 "빛을 받는 눈"이지 인간 눈이 아니다 — 인형 유리 눈의 광택.
검증: 심문 푸시인 프레임에서 눈에 하이라이트 점이 판독된다.

### P0-2. 시선 [2.5h]
gaze 트래킹: 대화 중 상대(플레이어 카메라)를 보고 · 증거가 제시되면 서류철 방향을 보고 ·
거짓 텔의 시선 회피(기존)와 자연 복귀. 고개 미세 추종(눈만 굴리지 말고 목이 2~3° 따라간다).
표정 대용: 진술 상태별 고개 각(경청 기울임·부인 시 미세 젓기) — 기존 상태기계 비트만 구독.

### P1-3. 조형 마감 [2h]
얼굴 도자기 유약 광택(미세 크랙 글레이즈) · 볼조인트 놋쇠 핀/이음 디테일 · 손가락 관절 마디.
림 응답: 재질 스펙큘러·시트 텀이 측광을 받아 실루엣 가장자리가 사는지(광원 신설 없이).

### P1-4. 배경 인형 3인 승계 [1h]
P0 결과물(눈·조형)을 도일·루이즈·프라이스에 적용 — 시선은 앰비언트 수준(가끔 플레이어를
따라 보는 정도, 과하면 소름이 아니라 코미디다).

  완결 라운드 원문("목각·평면 도색")과 같은 판독자 질문으로 전후 대조.
