## 2. 작업

### P0-1. 입장 게이트 + 타이틀 사운드 [2.5h] — 자동재생 정책의 유일한 통로
고지문 로딩 완료 시 자동으로 타이틀을 열지 말고 **"아무 키나 누르십시오"**(타자기 조판, D7 준수)
한 줄을 띄워라. 그 첫 입력(키/클릭)이 제스처가 되어 AudioContext 를 열고, 타이틀에서:
- **빗소리 앰비언스**(배경이 비 내리는 외관이니 디제틱이다 — 절차 생성: 광대역 노이즈 셰이핑,
  기존 dsp 문법) + **원거리 천둥 단발**(드물게, 비반복 간격) + **E1 저역 드론 얇게**(41.2Hz
  리트모티프 — "약간 무서운" 톤은 이 셋의 합으로. 곡을 깔지 마라, E7 비디제틱 0 계약의 정신 유지).
- 벨/체크인 진행 시 기존 `title:proceed` 흐름 불변 — 빗소리는 인트로 물소리로 크로스페이드.
- **제스처 전에는 어떤 소리도, 어떤 AudioContext 생성도 없어야 한다** — 콘솔 경고 0이 실격선이다.

### P0-2. 타이틀 비 애니메이션 [1.5h]
정적 이미지 위 절차 레인 오버레이(canvas — 가는 빗줄기 2~3층 시차·마키 광원 근처 미광 반짝임).
`prefers-reduced-motion` 존중(정적 유지). 성능: 타이틀 한정, 게임 진입 시 완전 해제.

### P0-3. '체크인' 명패 가독성 [40분]
음각 글자 대비 상향(잉크·에칭 하이라이트) + 명패 크기/광택 소폭 — 배경 사진 위에서 3초 내
판독이 기준. 호버 효과 유지. 시스템 폰트 금지 유지.

### P0-4. 하네스 진입 보정 [1h] — 게이트 위임분
`common.mjs boot()`: title 대기 전에 게이트 상태를 감지해 아무 키 1회 → title 대기(기존 프로브
전부 무수정 통과가 목표). `playthrough.mjs` 진입도 동일 보정. `shoot.mjs`(qa 경로)는 타이틀을
안 지나니 무변경 확인만. **보정 후 probe-guidance·probe-tell·probe-audio·완주 봇 4종 재실행
전건 PASS가 완료 조건이다.**

## 3. 검증

- 콘솔 0 (특히 제스처 전 오디오 경고 0 — 로딩 화면에서 30초 방치 후 확인).
- 비: 타이틀 연속 2프레임 diff — 빗줄기 영역 픽셀 변화 실측(정지 프레임엔 비가 안 보인다).
- 소리: 게이트 입력 후 RMS 타임라인 — 빗소리 바닥 성립·드론 검출(probe-audio 탭 재사용).
- 체크인: 타이틀 프레임 블라인드 채점 — "이 화면에서 무엇을 눌러야 하는지 3초 안에 알겠는가."
- 회귀: `cinematic:end` 사건 계약·조작 카드·인트로 드론 결박 불변(probe 4종 PASS로 증명).
