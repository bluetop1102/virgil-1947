## 2. 작업

### P0-1. 제출물 4 — AI 활용 기술 문서 완성 [3h] (`ai-tech.md`)
골격 → 완성. 이 프로젝트의 실제 강점이 여기 있다 — 재료가 전부 저장소에 있다:
- **다층 AI 파이프라인 실화**: 오케스트레이터(판정·발주·게이트) → 병렬 구현 세션(소유 분할·
  pathspec 커밋) → 독립 검증(기계 프로브 + 구현 컨텍스트 없는 블라인드 채점) 구조를 커밋
  이력과 발사문(PROMPT-go-*)으로 증빙.
- **검증 하네스**: judge-probes(RMS 타임라인·visibleText·상태 직렬화), 실측이 뒤집은 판정 사례
  (드론 레이스, 심문 -8dB 역전 → +9.4dB, 노출 클램프 전제 반증), 하네스 함정 3건(엔진 시계
  0.4배·낡은 판 PASS·교차 오염)과 그 대응.
- **AI 생성 에셋 2종 출처**: 타이틀 배경(§1.1)·BGM 정책(외부 CC-BY 채택 경위, §1.2).
- 사실만 쓴다 — 근거는 커밋 해시·문서 경로로 결박(grounded). 과장 금지.

### P0-2. 제출물 3 — 게임 소개·설명 문서 완성 [2h] (`game-guide.md`)
골격 → 완성: 컨셉(1947 LA 호텔 노어·마리오네트 아트 디렉션) · 조작(카드와 동일 4키+Esc) ·
플레이 흐름(체크인→수사→심문→2막 이양) · 심문 시스템(진실/의심/거짓·증거 결박·비가역) ·
스크린샷은 `frames/` 확정본 참조(S-E가 만든다 — 경로만 걸어라). STORY.md 와 사실 일치 검증.

### P0-3. 제출물 2 — 영상 촬영 플랜 확정 [1h] (`video-plan.md`)
30~60초 대본을 현재 빌드 기준으로 갱신: 타이틀(3s) → 벨→인트로 몽타주(8s) → 이양: 카드+독백
(5s) → 조사·획득(8s) → 심문: 푸시인·텔·증거 지목·긴장층(20s) → 서류철 경고 스트립 클로즈업
(5s) → 타이틀 아웃(3s). **소리가 절반이다**(J6) — 헤드폰 녹음 지시 포함. 촬영은 사람 몫 —
타임코드별 조작 대본(누르는 키까지)으로 써서 사용자가 1테이크에 찍게 하라.
