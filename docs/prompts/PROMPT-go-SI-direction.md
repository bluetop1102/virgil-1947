## 2. 작업

### P0-1. 심문 컷 어휘에 측면 로우앵글 1종 추가 [2.5h] — J3③
네 컷(S1 미디엄·S2 푸시인·S3 풀백·판정 리액션)이 전부 다이치 중앙·정면이라 거리만 다르다.
**한 컷**(권장: S3 또는 판정 리액션)을 측면 저각으로 — 5점 차폐 레이캐스트 통과를 전제로
camera.js 후보각 체계에 측면 프리셋을 추가하는 방식. 검증: probe-tell 재실행 3항목 PASS 유지 +
비전 채점("다섯 프레임의 카메라 구도가 몇 종류로 보이는가" — 3종 이상 판독이면 성립).

### P0-2. 인트로 트래킹 속도 완화 [1.5h] — J1
3차: "셔터를 더 줄이기보다 속도를 늦추는 쪽이 남았다." 벨홉 인형 앞 통과 구간의 카메라
속도를 낮추거나 체류를 짧게 우회해 얼굴 뭉갬 프레임 자체를 없애라. **INTRO 총 길이(30s
엔진초)와 `cinematic:end` 발화 시점 계약은 불변** — S-A 드론 결박·S-D 카드가 그 사건에
물려 있다. 검증: t=12~16 구간 0.7s 간격 캡처에서 벨홉 얼굴 윤곽 판독(비전 채점) + 완주 봇 PASS.

### P0-3. E2 0:22 "라디오가 잦아든다" 종결 통지 [40분] — HANDOFF 미처리분
현재 오디오가 자체 타이머로 우회 중이다. `cinematics.js` `_soundBeats()` 가 t=22 비트에서

이중 감쇠만 없으면 무해하니 통지 추가만 하고 등재).
