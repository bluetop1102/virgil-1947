# 발사문 S-M — 배회 오디오 튜닝 (사용자 실청취: "물 떨어지는 소리·주기적 북소리 너무 별로")

> 실행자: Claude 새 세션. 오늘 제출. **진단 없이 게인을 만지지 마라 — 사용자가 들은 그 소리를
> 먼저 특정한다.** 최종 판정자는 사용자 귀다 — 기계는 후보 특정과 회귀 방지만 한다.
> 배포는 게이트 몫.

## 0. 먼저 읽는다

1. `src/audio/ambience.js` — 배회 스웰·원거리 단발음(S-J 신설). 규율 주석("바닥 위 3~8dB").
2. `src/audio/engine.js` `_levels()`·waterBus — 물 상시 앰비언스(flow/air/tank).
3. `docs/submission/audio-listen-check.md` — 사용자 실청취가 이 시트의 실패 항목이다.
4. `tools/judge-probes/common.mjs` — 함정 3건.

## 1. 소유 파일

```
src/audio/**  docs/submission/audio-listen-check.md(해당 항목 갱신)
```
(S-L 이 render/config/settings 를 만지는 중 — 오디오와 무충돌. 커밋은 pathspec.)

## 2. 작업

### P0-1. 발화원 특정 [1h]
로비 도보 3분 프로브(probe-audio 탭 재사용 + sfx/ambience 이벤트 페이지 탭): 사용자가 들은
②주기적 북소리(후보: pipe.knock·tank.hollow 단발음, 스웰 저역 펄스) ①물 떨어지는 소리
(후보: water.drip sfx, waterBus tank 성분, 발소리 젖은 재질)를 **이벤트 타임라인과 대조해
어느 큐가 몇 초 간격·몇 dB로 났는지 표로** 만든다. 추정 금지 — 로그로 특정.

### P0-2. 처방 [1.5h]
특정된 발화원에 대해:
- **단발음**: 간격을 "수 분에 1회, 비반복"으로 대폭 확대 + 게인 하향(바닥 위 3dB대).
  "드물어야 예감이고, 잦으면 소음"이 판정 기준이다. 로비 한정으로 끄는 것도 후보다(로비는
  라디오·긴장층이 이미 있다 — 단발음의 서사 자리는 2막 복도다).
- **물소리**: 상시 성분은 존재감을 낮추되 0으로 만들지 마라(수압 서사 결박). drip 계열
  이벤트성 소리는 간격·게인 재조정.
- 스웰이 범인이면: 주기 유지하되 진폭 하향(밀도 변조는 유지 — J6 기복 실측이 걸려 있다).

### P0-3. 회귀 검증 [1h]
probe-audio 4항목 PASS 유지(특히 심문 역전·배회 무음 0) · 기복 실측이 죽지 않았는지
(12초 창 표준편차가 개선 전 1.394 이상 유지) · test-audio 전건 · 완주 봇 · 콘솔 0.
`audio-listen-check.md` 의 해당 항목을 "무엇이 바뀌었고 무엇을 들어야 하는지"로 갱신.

## 3. 완료 보고
발화원 특정 표(큐×간격×dB) · 처방 전후 값 · 회귀 검증 결과 · **사용자 재청취 안내 한 줄**
(어디를 걸으며 무엇이 안 들려야 정상인지). 배포 금지 — 게이트가 S-L 회수분과 묶어 배포한다.
