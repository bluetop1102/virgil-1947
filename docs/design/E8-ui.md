# E8 — UI·부수 기능

> 수사노트·설정·로딩·저장·계측의 사양. 전 UI에 **1947 물성 원칙(P6·D7)**: 시스템 폰트·
> 기본 버튼·라운드 코너 카드·이모지 0 — 모든 화면 요소는 1947년의 물건(종이·잉크·놋쇠·
> 베이클라이트)으로 읽혀야 한다. 감사 실측 결박: MASTER-PLAN §8의 방식 결정
> (품질 전환=`?q=` 리로드 · 키바인드=범위 외)은 재론하지 않는다.

## 1. 수사노트 (`ui/notebook.js` — 기존 목표 달성분 승계 + v2 확장)

기존: 1947 종이 소품으로 읽힘(D7 무발생) — 이 물성 기준선을 유지한 채 3확장.

- **증거 면**: 수집 증거 목록 + 검사 뷰어. **사진 스크럽(C3)**: `photos` 검사 시 4장을
  드래그/방향키로 넘긴다(인화지 넘기는 모션). `photos-4` 플래그 후 4번째 장에서 유리 반사
  영역 상호작용 활성 → 2단 줌(전체→반사 크롭). 줌 배율 2단 고정, 자유 줌 없음.
- **인물 면**: 인물별 진술 기록. **소각된 진술은 줄이 그어진 채 잔존**(E5 §2.3 — 잉크로
  그은 취소선, 지워지지 않는다). 소각으로 닫힌 재심문은 "더 묻지 않는다" 표기.
- **괴담 면**: `lore:heard` 축적. 증거 면과 **다른 지질**(신문 스크랩·메모 쪼가리 콜라주 —
  타자 정서가 아니라 풀로 붙인 잡동사니)로 물리적 구분 — 괴담은 증거가 아니라는 시스템
  발화(E7 §4). 지목판에 나타나지 않는다.

## 2. 설정 (`ui/settings.js` 신규 — order 80, 자동 등록)

물성: 프런트 서류함 카드 + 객실 안내판 스타일 — 항목은 타자된 카드, 값 변경은 카드를
넘기거나 놋쇠 다이얼을 돌리는 상호작용.

| 항목 | 방식 | 반영 |
|---|---|---|
| 품질 프리셋 | `?q=` URL 재작성 + 리로드 (감사 결론 승계 — 무리로드 전환은 비경제) | 리로드 시 |
| FOV | 60~80, `camera.fov`+`updateProjectionMatrix()` | 즉시 |
| 마우스 감도 | `player.js` SENS 인스턴스 필드 | 즉시 |
| 자막 | `subtitles.js` 플래그 | 즉시 |
| 볼륨 | 기존 마스터 게인 노드 | 즉시 |
| 키바인드 | **범위 외** (키맵 테이블 부재 — 백로그 명시, P 계획 불포함) | — |

`settings:changed` 버스 발신 · localStorage 키 `virgil.settings`(자체 키, state와 분리).

## 3. 로딩 화면 (P1 필수 — 베이크·컴파일 수 초의 블랙스크린 제거)

- 검은 바탕에 타자기 타건으로 찍히는 **허구 고지문**(로딩 시간의 서사화):
  "이 이야기의 인물·사건·호텔은 전부 허구다. 실존하는 어떤 인물·사건·업체와도 무관하다."
  — 이 고지는 재허구화 계약(MASTER-PLAN §1)의 화면 측 이행이다.
- 진행률: 하단에 객실 열쇠 고리가 하나씩 걸리는 카운터(텍스트 % 병기 없음 — 물성 유지).
- 로딩 완료 → E2 첫 30초 시퀀스로 컷 없이 연결(물소리가 로딩 중에 먼저 시작된다).

## 4. 저장 (체크포인트 — 비가역 코어의 지지대)

- **막 경계 자동 저장만. 수동 저장·로드 없음. 슬롯 1개.** 수동 세이브/로드는 소각 회피
  루트가 되어 U1(비가역)을 무너뜨린다 — 이 제한은 편의 기능 누락이 아니라 코어 설계다.
  타이틀 화면 선택지: "이어서"(마지막 체크포인트) / "처음부터"(슬롯 덮어쓰기 경고 1회).
- 구현: `state.js` 직렬화 활용 + **역직렬화 신설** — core 잠금 회피를 위해 역직렬화는
  gameplay 측 모듈이 소유(`gameplay/save.js` 신설, `checkpoint:saved {act}` 발화).
- 직렬화 범위: 증거 소지·소각 상태·플래그·막·심문 점수 (소각이 저장에 포함되어야
  "리로드로 되돌리기"가 불가능해진다 — E5 [구현] 결박).

## 5. 프레임타임 계측 (`?stats=1` — QA 전용, 플레이어 비노출)

통계 오버레이: frametime p50/p95·드로우콜·메모리. 샷 하네스에 프레임 예산 게이트 추가
(high 60fps / medium 30fps). D7 면제 대상(플레이어에게 보이지 않는 개발 도구).

## [플레이어]

Tab을 누르면 게임이 멈추는 게 아니라 손이 노트를 든다. 타자로 정서된 진술 기록 사이에
잉크로 그어진 줄이 하나 있다 — 지난 시간에 태운 것. 지우개는 없다. 사진 네 장은 인화지
그대로 끼워져 있고, 넘기다 보면 네 번째 장의 유리 반사에서 손이 멈춘다. 뒤쪽 지면은
다르다 — 신문 쪼가리, 낙서를 옮겨 적은 메모, 풀 자국. 증거의 지면과 소문의 지면은 종이부터
다르다. 설정을 열어도 메뉴가 아니라 프런트 서류함이 나오고, 게임을 껐다 켜도 돌아갈 곳은
마지막 막의 문턱뿐이다 — 태운 것은 태워진 채로 있다.
