# E9 — 게이트·루브릭

> 루브릭 항목·게이트 기준의 진실원은 `docs/AAA-RUBRIC.md` v2다. 이 문서는 게이트 체계
> 총괄·기계 게이트 총목록·goal 계약 형식을 지휘한다. 기획 루브릭(M1~M7)의 진실원은
> `graders/grader-M.md`.

## 1. 게이트 체계 — 순서와 이유

| 순서 | 게이트 | 기준 | 판정 수단 | 시점 |
|---|---|---|---|---|
| 0 | **기획 게이트** | M1~M7 전 항목 8+ · factcheck PASS · 사용자 게이트 2회 | 블라인드 채점자 + 신선 테스트 + 기계 | 이 세션 |
| 1st | **게이트 4 (플레이)** | P1~P6 전 항목 8+ | 완주 봇·시퀀스 캡처·상관 검사 | P3 |
| 2nd | **게이트 2 (내러티브)** | N1~N8 전 항목 8+ | N-판정자 | P3 |
| 3rd | **게이트 1 (그래픽)** | G1~G10 전 항목 8+ · D 실격 0 | G-판정자 + 픽셀 회귀 | P5 (동결 해제 후) |
| 4th | **게이트 3 (블라인드)** | 상용 오인 또는 즉답 불가 | 무라벨 비교 | 최종 |

**그래픽이 마지막인 이유(재정의 근거)**: 판 위에 게임이 있어야 블라인드 비교가 성립하고,
레벨 지오메트리가 확정돼야 조명·구도 튜닝이 무효화되지 않는다. 정지샷만 보는 채점기가
플레이를 못 본 것이 구 공정의 국소 최적화 원인이었다 — P축은 판정 수단 자체가 다르다
(스크린샷이 아니라 로그·완주·시퀀스).

## 2. 기계 게이트 총목록 (goal 루프가 소비하는 통과 조건 은행)

| 게이트 | 도구 | 실행 시점 | 상태 |
|---|---|---|---|
| 사실 그래프 F1~F4+R1~R3 | `tools/factcheck.mjs` | 내러티브 데이터 변경마다 (커밋 게이트) | **가동 중 (PASS)** |
| 픽셀 회귀 | `tools/pix.mjs diff` + `shots/_baseline/` | 시각 변경 라운드마다 | 가동 중 (동결 감시) |
| 완주 봇 3경로 | `tools/playthrough.mjs` (신설) | 게임플레이 변경마다 | P1 티켓 |
| 텔 상관 (P5) | factcheck 확장 — script v2의 텔 발화 상관 | 스크립트 변경마다 | P1 티켓 |
| 콘솔 에러·경고 0 | 샷 하네스 기존 | 전 라운드 | 가동 중 |
| 계약 린트 | 커밋 훅 grep 5종: materials 밖 `Mesh*Material` · atmosphere 밖 `*Light` · `Math.random(`/`Date.now(`/`performance.now(` · 500줄 초과 · 화면 표출 "세실" | 커밋마다 | P0 티켓 |
| 프레임 예산 | `?stats=1` 계측 — high 60fps / medium 30fps | 레벨 라운드마다 | P1 티켓 |
| 판정 배터리 (2단) | 정답/오답/무관 60건 오판 0 | 커널 스왑 머지 조건 | P4 티켓 |

## 3. goal 계약 형식 (전 구현 Phase 공통 — 중단 조건 없는 goal 루프 금지)

```
/goal {목표 1문장}
통과 조건: {위 §2 은행의 부분집합} + {루브릭 항목 지목}
중단 조건: 라운드 상한 N회 · 토큰 상한 M · 세션 한도 근처 팬아웃 금지(직렬 전환)
```

세 필드 전부 **필수**다 — 토큰 상한이 빠진 goal은 발사 금지(에이전트 팬아웃 비용 게이트
승계). 기준 수치: P0 = 서브에이전트 토큰 500만 · P1 = 1,500만(CECIL 복도 실측이 기준) ·
이후 Phase는 발사문 작성 시 직전 Phase 실측으로 갱신. 상한 도달 시 라운드 경계에서 중단하고
ROUNDS.md에 인수인계를 남긴다.

라운드 규율(승계): 라운드 = 단일 담당 · 단일 목표 · 사전 기준선 → 사후 기계 게이트.
커밋은 라운드 단위 세분. 회귀면 롤백 — 판 갱신은 개선일 때만.

## 4. 루브릭의 지위 — 프록시 경고 (리스크 대장 승계)

P 점수가 오르는데 플레이가 재미없다면 루브릭이 프록시화된 것이다. 최종 심급은 게이트 3
(블라인드)과 실플레이 소감이며, P축 점수 인플레가 감지되면 항목 자체를 재설계한다.
루브릭은 목적이 아니라 측정기다.

## [플레이어]

플레이어는 게이트를 보지 않는다 — 게이트가 걸러낸 것만 만난다. 진행 불능에 빠지지 않고
(F3), 어느 거짓말 앞에서도 반박 수단이 세상 어딘가에 존재하고(F1), 첫 30초 안에 이 게임이
무엇인지 알게 되고(P2), 3분 넘게 할 일 없이 배회하지 않는다(P3). 텔을 외워서 정답기로
쓸 수 없고(P5), 화면 어디에도 2026년의 웹이 새어 들어오지 않는다(P6·D7). 게이트의 품질은
플레이어에게 "잘 만들어졌다"가 아니라 "걸리는 데가 없다"로 체감된다.
