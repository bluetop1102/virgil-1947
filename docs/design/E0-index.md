## 0. 명칭 검증 — "호텔 버질(Hotel Virgil)" 확정 (2026-08-05)

웹 검색 검증 결과, 충돌 없음으로 판정하고 가제를 **확정 표기**로 전환한다.

- "The Virgil" — LA 이스트 할리우드의 실존 **바·라이브 공연장**(4519 Santa Monica Blvd, 21+).
  숙박업이 아니며, 1947년 허구 호텔과 업종·시대·서비스가 겹치지 않는다.
- "Hotel Virgil"이라는 실존 호텔·등록 상표는 검색에서 확인되지 않음. St. Virgil(잘츠부르크,
  오스트리아)은 교육시설 부속 숙박이며 무관. Virgil(NY·SD)은 지명.
- 무대 "버질 애비뉴"는 LA 실존 도로명 차용(MASTER-PLAN §1 — 호텔은 가공). 시작 화면 허구
  고지문은 유지·강화(§1 승계).
- 잔여 조항: 외부 공개(스토어 등록·배포) 시 상표 데이터베이스(USPTO) 재확인. 저장소 폴더명
  `cecil-hotel-noir`는 내부 코드네임으로 잔존 허용.

**화면 표출 규칙**: 표출 텍스트의 "세실/Cecil" 0건(grep 게이트 — PROMPT-build-p0의 계약 린트).
설계 문서(docs/design/*)에서 작품명은 VIRGIL/버질로만 쓴다. 코드 식별자(`__CECIL__` 등)는
코드네임으로 잔존 허용, 정리는 P0 이월.
