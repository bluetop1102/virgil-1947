# 라운드 로그 — 복도 그래픽

프로세스: **기준선 고정 → 담당 1명 → 촬영 → `tools/pix.mjs diff` → 개선이면 기준선 갱신, 회귀면 롤백.**
기준선은 `shots/_baseline/corridor.png` (라운드마다 갱신). `corridor-r4-current.png` 는 라운드5 진입 시점의 원본 기록이라 갱신하지 않는다.

```bash
SHOT_PORT=59xx node tools/shoot.mjs --out shots/rN atmo-corridor-night
node tools/pix.mjs diff shots/_baseline/corridor.png shots/rN/atmo-corridor-night.png --heat /tmp/heat.png
```

A/B 진단은 `--ab <file.json>` 으로 한 세션에서 변종을 돌린다(`[{tag, js}]`).
**광원 주변 A/B는 `pipeline.composite.mat.uniforms.uHalation.value = 0` 을 먼저 걸어야 한다** —
composite은 `pipeline.effects`가 아니라 CORE 직속이라 `--off`가 닿지 않는다.
그리고 QA 모드 엔진은 RAF를 돌리지 않으므로 **상태를 바꾼 뒤 반드시 다시 settle** 해야 한다
(하네스가 자동으로 한다). 이걸 놓쳐서 이전 세션 A/B가 전부 무효였다.

## R5-1 — 재질 오버레이 스미어 (해결)

**증상.** 화면 전체를 가로지르는 긴 가닥. 포스트 6개를 전량 제거해도 잔존.

**기각한 원인** (전부 A/B로 확인, 다시 파지 말 것):
포스트 6패스 · 헐레이션 · 물얼룩/그을음 밴드(uCD) · 월드 그런지(uCA.z) · 매크로 damp(uCC.y) ·
디테일 노멀(uCB.y) · 스토캐스틱 타일링 · 이방성 필터링(aniso 16·밉 정상) · 정점 컬러 페인트.

**진짜 원인.** `THREE.Material.copy()` 는 `defines` / `onBeforeCompile` / `customProgramCacheKey` /
`onBeforeRender` 를 복사하지 않는다(three.core.js `Material.copy` 필드 목록으로 확인).
`kit-mat.js` 의 `wearMat()` 이 라이브러리 재질을 클론해 정점 컬러 마모를 얹는데, 그 클론이
`applyCecil` 이 심은 **CECIL_TRIPLANAR·CECIL_STOCH·CECIL_POM·CECIL_FLOW 와 주입 청크를 통째로
잃고** 기본 PBR + 메시 UV 로 되돌아갔다. 런타임 계측이 결정적 증거다 —
같은 `wallpaper.damask.green` 인데 원본 재질은 `defines: [STANDARD, PHYSICAL, CECIL_TRIPLANAR]`,
wear 클론은 `defines: [STANDARD, PHYSICAL]`.
복도 벽 베니어는 `uv 0..1 이 17.3m × 1.79m` 인 판이라, 트리플래너를 잃은 순간 벽지 한 장이
복도 전체에 늘어나 화면을 가로지르는 가닥이 됐다. `wear`/`vcol` 메시가 전부 이 경로를 타므로
복도만이 아니라 **프로젝트 전역**에 걸려 있던 결함이다.

**수정.** `wearMat()` 에서 클론이 잃은 것을 복원하고(`defines` 복사, `onBeforeCompile` /
`customProgramCacheKey` 를 클론이 아니라 **원본**에서 체이닝), 재질이 아직 `pending` 이면
캐시하지 않는다.

**측정.** 기준선 `corridor-r4-current.png` → `shots/r5-a`
`meanDiff 12.3/255 · 변화 53.4%` / 전역 반딧불 `1.666 → 1.202` / 뭉갠 타일 0 / 게이트 PASS.
부수 확인: 마루 널 이음매·나뭇결이 살아났고, 심사자가 D1로 지적한 카트 망사 도트 끊김이 걷혔다.

**게이트 자체의 교정.** 첫 판본이 이 개선을 두 번 회귀로 오판해서 지표를 고쳤다.
- 전역 스미어 지표(`|dI/dx|` 비 → 64px 구조텐서 코히런스)는 **둘 다 폐기**. 벽지 격자 같은
  정상 방향성 무늬와 스미어를 가르지 못한다. 스미어는 "국소 디테일 소실"로만 잡는다.
- 반딧불 판정을 4이웃 → **8이웃**. 4이웃은 1px 대각선(마루 널 이음매)을 반딧불로 셌다.
- 국소 디테일 감소는 **결과가 절대 바닥값(2.5) 미만으로 뭉갤 때만** 회귀. 에일리어싱이 걷히면
  라플라시안은 정당하게 떨어진다.

## R5-2 — 천장 형광등 플레이스홀더 (D4, 해결)

**증상.** 하우징·엔드캡·소켓이 없는 순백 캡슐 두 개 + 어두운 돔. 화면에서 "흰 알약"으로 읽힘.

**수정.** `makeFixture('ceiling')` 형광 분기를 실제 표면부착 채널 기구로 다시 지었다 —
접힌 강판 채널(`CHANNEL_PROF` 스윕) · 엔드플레이트 · 놋쇠 텅스톤 소켓 · 백색 에나멜 반사판
(`REFLECTOR_PROF`) · 채널 밑으로 내려온 관 · 천장 캐노피 2점.

**두 번 갈아엎은 이유(기록).**
1. 하우징을 `steel.galvanized` 로 두니 밝은 천장을 배경으로 **더 밝은 청회색 평판**이 됐다.
   아래에서 올려다본 기구 몸통은 어두운 실루엣이어야 관이 광원으로 읽힌다 → `bakelite.black`.
2. 반사판을 PBR로 두니 채널 속이 IBL만 받아 차가운 청회색이 됐다. 관은 실광원이 아니라
   무조명 이미터라 반사판을 못 비춘다 → 반사판도 셰이드(무조명 이미터)로 그린다.
   소켓은 몸통과 같은 검정이면 끝이 뭉개져 놋쇠로 값을 갈랐다.

**측정.** 게이트 PASS. 반딧불 `1.202 → 1.150`, 디테일 `30.26 → 30.51`, 뭉갠 타일 0.
변화는 천장 밴드(y=160) 세 기구에 국한 — 다른 영역 무회귀.

## R5-3 — 재질 클론 결함의 나머지 절반 (`wetify`) + 콘솔 경고 0 복구

R5-1 을 고친 뒤 전 공간 촬영에서 `THREE.Texture: Unable to serialize Texture.` 경고 1건이

렌더타깃 텍스처에서 경고를 내고, defines/onBeforeCompile 을 안 옮겨 cecil 주입을 잃는다.

**수정.** `kit-mat.js` 에 `cloneMat(src, {patch, key})` 를 두고 `wearMat` 과 `wetify` 가
둘 다 그것을 쓰게 했다. 재질을 복제하는 자리는 앞으로 전부 이 함수를 거친다.

**측정.** 전 공간(6컷) 콘솔 `[]`. 복도는 **바이트 동일**(meanDiff 0) — 리팩터가 복도에
무영향임을 기계로 확인. 옥상은 처음으로 의도한 재질계를 받아 골재·물웅덩이 구조가 드러났고
평균 휘도가 `113.5 → 126.0` 으로 떴다 — **옥상 확장 라운드에서 값 재조정이 필요하다**(미결).

**노출 오염 주의.** `taa.render`를 통째로 스텁하면 composite이 빈 타깃을 읽어 자동노출이 444까지

## R6-2 — 형광 비플랑크 벡터 (적용 · 화면 효과 측정 하한 이하)

**수정.** `core/util.js` 는 잠금이라 `kelvin()` 을 못 고친다. `atmosphere.js` 에 `offLocus()` 를

**왜 안 보이는가(실측).** 복도에서 형광은 `atmo.ceiling` 1등(cd 5.2)뿐이고 벽등 3등이
14.9~22.7 이다. 게다가 **화면의 형광관 자체가 호박색으로 렌더된다** — 관 픽셀 R−B 가
`+58 ~ +71` 이다(4500K 라면 그레이딩 전 +25 이하여야 한다). 발광부가 `hot` 3.2배로 밀려

**따라서 G1 +1.7 은 광원 색만으로는 도달 불가다.** 복도가 단일 색온도로 읽히는 진짜 원인은

다음 담당자는 발광부 `hot` 배율과 BULB_FRAG 의 림 색을 광원 색온도에 종속시키는 쪽을 봐야 한다
