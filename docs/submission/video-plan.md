# 제출물 2 — 플레이 동영상 촬영 플랜 (30~60초)

> 요강: **실제 플레이 화면. AI 조작·합성 불가.** 화면 녹화 그대로여야 한다.
> 컷 편집·자막·BGM 추가는 "합성"이 아니지만, **AI 생성 영상·AI 조작 플레이는 실격 사유**다.
> 사람이 직접 조작한 실플레이만 쓴다.

## 0. 제약이 만드는 설계

30~60초는 게임을 설명할 시간이 아니라 **한 가지를 각인시킬 시간**이다.
이 게임의 각인점은 그래픽도 스토리도 아니라 **"틀리게 내민 증거는 사라진다"** 하나다.
따라서 영상의 뼈대는 소각 1회를 실시간으로 보여주는 것이다.

## 1. 구성 (총 55초 목표)

| 구간 | 초 | 화면 | 왜 이 컷인가 |
|---|---|---|---|
| A | 0–8 | 첫 30초 시네마틱 발췌 — 검은 화면 + 물소리, 타이핑 자막 3줄, 로비 페이드인 | 톤·시대·장르를 8초에 선언. 자막이 이미 대사를 대신한다 |
| B | 8–18 | 로비 수색 — 숙박부 관찰 클로즈업, 열쇠 걸이의 빈 고리 2개가 한 프레임에 | "수사한다"를 말 없이 보여주는 가장 짧은 컷 |
| C | 18–34 | **다이치 심문 C1** — 진술 → 3선택 표시 → 거짓 선택 → 노트 열림 → 숙박부 지목 → 카메라 푸시인 → 상대가 반 발짝 물러선다 | 코어 루프 전체가 한 호흡에 들어가는 유일한 구간 |
| D | 34–44 | **소각** — 같은 심문의 다른 진술에서 오답 증거 제시. 카메라 반 발짝 후퇴 + 룸톤 -6dB. 노트에 잉크로 그어진 취소선 | 각인점. 여기서 UI 설명 자막을 **넣지 않는다** — 몸이 먼저 아는 것이 설계다 |
| E | 44–52 | 9층 복도 → 942호 → 옥상 비 (3컷 빠르게) | 범위가 있다는 것만 보여준다. 스포일러 금지 |
| F | 52–55 | 타이틀 카드 + 링크 | — |

**넣지 않는 것**: 엔딩·범인·물탱크 발견. 3막 옥상은 "비 오는 옥상"까지만.

## 2. 촬영 규약

- **해상도·프레임**: 1920×1080 60fps 화면 녹화. 브라우저 전체화면, 탭·북마크바 비노출.
- **품질 프리셋**: `high` 이상. 촬영 전 `Esc → 설정`에서 확인하고, 설정 카드는 녹화에 넣지 않는다.
- **입력**: 사람이 직접 조작. 완주 봇(`tools/playthrough.mjs`)의 자동 주행은 **쓰지 않는다** —
  "AI 조작 불가" 조항에 걸린다. 봇은 촬영 **리허설**(동선·타이밍 확인)에만 쓴다.
- **소리**: 게임 내 오디오 그대로. 외부 BGM을 얹지 않는다 — D 구간의 -6dB 침묵이 죽는다.
- **테이크**: C·D 구간은 실패해도 다시 찍는다. 소각은 회차 안에서 비가역이므로
  **테이크마다 새 회차**(`?resume=` 없이 새로 시작)로 간다.
- **자막**: 게임 자체 자막만. 설명 자막·화살표·확대 강조를 얹지 않는다.

## 3. 촬영 전 선행 조건

이 영상은 P1 수직 슬라이스가 끝나야 찍을 수 있다. 필요한 티켓(`data/manifest/`):

| 구간 | 필요 티켓 |
|---|---|
| A | T-P1-07 (cin-intro) · T-P1-05 (로딩·타이틀) |
| B | T-P1-01 (로비 정식 레벨) · T-P1-10 (상호작용) |
| C·D | T-P1-04 (심문 E2E) · T-P1-09 (심문 UI) · T-P1-08 (카메라·룸톤) · T-P1-02·03 (리그·텔) |
| E | P2 레벨 3종 — **미착수**. 대체안: 기존 QA 프로브(`?scene=`)의 복도·942·옥상 화면을 쓴다 |

E 구간 대체안은 정식 레벨이 아니라 프로브라 상호작용이 없다 — **걸어 지나가는 컷으로만** 쓴다.
프로브를 "플레이 화면"으로 제시하는 것 자체는 실플레이 화면이므로 요건 위반이 아니다.
