# 제출물 2 — 플레이 동영상 촬영 대본 (52초)

> 공식 요건: **30~60초 YouTube 영상 · 실제 게임 플레이 중심 · 사람이 직접 조작 · AI 조작/합성 및
> 타인 영상 사용 금지.** 공개 또는 일부공개로 올리고 심사 종료까지 유지한다.

이 대본은 사람이 한 회차를 직접 플레이해 녹화한 뒤 **하드컷만으로** 52초를 만드는 기준이다.
봇·AI 생성 프레임·보간 프레임·합성 게임 화면은 한 프레임도 사용하지 않는다.

## 0. 촬영 전 P0 확인

증거 규칙은 커밋 `42a3814`에서 실제 동작에 맞췄다. 증거 아이템은 남지만, **한 번 내민 판정은
무를 수 없고 오답이면 해당 진술과 하류 정보가 이번 회차에서 영구 폐쇄된다.** fresh 검증은
`test-interrogation` 108/0, `--burn` 9/0, 1막 완주 PASS다.

다만 최종 영상은 모든 제작 세션 종료·음원 귀속 해소·소스/Pages 동결 뒤에만 촬영한다. 영상에
보이는 노트 고지가 **「내민 증거는 무르지 못한다」**인지 리허설에서 먼저 확인한다. Shift 행 추가 뒤
발견된 조작 카드 하단 잘림은 `999dafa`에서 해소했으므로, 최종 Pages에서도
**이동·달리기·조사·수첩·카드 5행**이 모두 보이는지 확인한다.

## 1. 이 영상이 남길 한 문장

> **진술을 듣고, 거짓이면 증거를 직접 고른다. 잘못 고르면 그 진술은 다시 열리지 않는다.**

영상의 절반을 심문에 배정한다. 마리오네트의 몸짓, 종이 선택지, 증거 서류철, 오답 뒤 카메라와
소리의 후퇴가 한 흐름으로 보여야 한다. 외부 BGM을 덧씌우지 않는다. 게임 안 라디오·CC BY 긴장층과
절차 생성 룸톤이 그대로 들리게 한다.

## 2. 촬영 전 세팅

| 항목 | 값 |
|---|---|
| 해상도·프레임 | **1920×1080 · 60fps** |
| 브라우저 | 최신 Chromium 계열 · **전체화면(F11)** · 탭/주소창/북마크바 비노출 |
| 오디오 | 시스템 오디오 녹음 ON · 게임 음량 100% · 헤드폰 착용 |
| 품질 | `high` |
| 회차 | 타이틀에 **「체크인」**이 보이는 새 회차 |
| 입력 | 사람이 직접 키보드·마우스 조작 · 급격한 시선 회전 금지 |

최종 배포본 <https://bluetop1102.github.io/virgil-1947/> 을 사용한다. 로컬 개발 서버가 아니라
실제 제출 링크로 찍어야 영상과 심사 링크가 같은 빌드임을 증명할 수 있다.

리허설에서 `node tools/playthrough.mjs --fast --act 1`로 순서를 익힐 수는 있지만, **그 화면은
본 영상에 사용할 수 없다.** 본 촬영은 반드시 사람이 직접 조작한다.

## 3. 52초 편집표

| 구간 | 길이 | 보여 줄 것 |
|---|---:|---|
| A. 타이틀 | 3초 | 비 내리는 호텔 외관 · `HOTEL VIRGIL` · 놋쇠 벨 · 「체크인」 |
| B. 벨과 인트로 | 6초 | 벨 타격음 · 사건 자막 · 로비 트래킹 중 가장 안정적인 두 컷 |
| C. 조작 이양 | 4초 | 손글씨 조작 카드 5행 · 첫 목표 독백 |
| D. 조사 | 7초 | 숙박부 프롬프트 → E → 증거 슬립 · 열쇠 걸이 관찰 |
| E. 심문 | 24초 | 진술 → 몸짓 → 종이 선택지 → 거짓 → 증거 선택 → 오답 반응 |
| F. 제출본 종료 | 8초 | 같은 회차의 심문 종료 후 → 직접 이동 → 격자문 프롬프트 → E·게이트음 |
| **합계** | **52초** | 공식 30~60초 범위 안 |

### A — 타이틀 (3초)

페이지가 완전히 로드된 뒤 4초간 아무것도 누르지 않는다. 비, 마키 전구, 젖은 아스팔트 반사가
움직이고 제목·벨·「체크인」 명패가 한 프레임에 있는 3초를 쓴다.

### B — 벨과 인트로 (6초)

놋쇠 벨을 클릭한다. 인트로 동안 키보드와 마우스를 건드리지 않는다. 벨 타격음부터 사건 자막이
두 줄 이상 읽히는 구간을 고른다. 빠른 트래킹으로 형체가 뭉개지는 프레임이나 어절 중간에서
자막이 갈리는 프레임은 버린다.

### C — 조작 이양 (4초)

인트로 끝에 손글씨 카드와 형사의 첫 목표 독백이 함께 뜬다. 카드가 보이는 동안 입력하지 않는다.
`이동 W A S D · 달리기 Shift · 조사 E · 수첩 Tab · 카드 Esc` 다섯 행이 읽히는 구간을 사용한다.

### D — 조사 (7초)

1. 데스크의 펼친 숙박부를 천천히 화면 중앙에 둔다.
2. 종이 프롬프트가 나타나면 **E**. 획득음, 증거 슬립, 오브젝트 상태 변화가 끝날 때까지 기다린다.
3. 시선을 천천히 열쇠 걸이로 옮겨 빈 고리를 비춘다. 급격한 회전은 하지 않는다.

편집에서는 프롬프트 1초, E 뒤 반응 3초, 열쇠 걸이 이동·관찰 3초를 쓴다.

### E — 심문 (24초) · 영상의 중심

1. 다이치를 화면 중앙에 두고 **E**. 심문 저역이 올라오는 동안 3초간 입력하지 않는다.
2. 첫 진술을 듣고 손·어깨·시선을 프레임에 둔다.
3. 카운터 위 `1. 진실 · 2. 의심 · 3. 거짓` 쪽지가 놓이면 **3**을 누른다.
4. 수사노트가 열리면 경고와 증거 문서가 읽히도록 2초 기다린다.
5. 방향키로 **숙박부**를 선택하고 **Enter**. 첫 진술은 참이므로 이 제시는 오답이 된다.
6. 다이치의 짧아진 반응, 카메라가 물러나는 움직임, 룸톤이 가라앉는 순간까지 손을 뗀다.

편집 배분은 심문 진입·긴장층 4초, 진술과 몸짓 5초, 선택지 4초, 증거 선택 5초, 오답 반응 6초다.
선택지 쪽지와 증거 서류철이 각각 최소 2초는 완전히 읽혀야 한다.

오답 시연은 게임 규칙을 보여 주기 위한 촬영용 회차다. 이후 정답 진행을 따로 촬영한다면 반드시
새 회차로 시작한다.

### F — 제출본 종료 (8초)

같은 오답 회차에서 남은 진술을 모두 처리한 직후로 하드컷한다. 자유 이동을 되찾은 장면 2초,
격자문까지 직접 걷는 장면 3초, 프롬프트 1초, **E**와 게이트음 2초를 쓴다. 동결 전 검증본은 이
입력에서 문이나 새 장면을 움직이지 않으므로 보이지 않는 “전환 반응”이나 “입력 승인”을 영상이
증명한다고 주장하지 않는다. 이 컷은 오답 뒤에도 같은 회차의 직접 조작이 격자문까지 이어진다는
범위만 보여 준다. 별도 엔드카드·링크·화살표를 합성하지 않으며 플레이 URL은 YouTube 설명란과
게임 소개 PDF에 넣는다.

경로 사전검증에서 S1 오답 소각 뒤 S2·S3·S4·S5를 처리하면 `deitch.ended=true`가 되고, 같은 상태로
격자문을 조사했을 때 게이트음과 `act:enter { act: 2 }`가 발화했다. 다만 room·문 메시·시네마틱은
변하지 않는 것도 동적 프로브로 확인했다. 따라서 E와 F는 새 회차를 섞지 않되 내부 `act:2`는 테스트
근거로만 남기고, 영상은 관찰 가능한 직접 이동·프롬프트·입력·소리만 주장한다.

## 4. 편집 규약

- 컷 전환은 **하드컷만** 사용한다. 크로스페이드, AI 보간, 생성 프레임, 화면 합성은 사용하지 않는다.
- 설명 자막·화살표·확대 강조를 얹지 않는다. 게임 자체 자막과 UI만 사용한다.
- 외부 BGM·효과음을 추가하지 않는다. 원본 시스템 오디오를 유지한다.
- 브라우저 UI, 개발자 도구, 녹화 알림, 마우스 커서는 최종 프레임에 남기지 않는다.
- 스포일러가 되는 2·3막 설계, 범인, 엔딩 자료는 넣지 않는다.
