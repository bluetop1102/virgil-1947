# 오디오 청감 확인 — 헤드폰 8분 (N7)

> 리뷰(`docs/reviews/fable-experience-2026-08-08.md` N7)는 2회 모두 **판정 보류**다 — 헤드리스라
> 소리를 못 들었다. 기계가 못 본 유일한 축이고, 사용자 실플레이 피드백("효과음이랑 BGM이 적당하지
> 않은 것 같다")도 여기에 걸렸다. 아래는 **코드로는 판정이 불가능한 것만** 남긴 목록이고,
> 각 항목은 "자연스러운가" 같은 감상이 아니라 **한 번 듣고 예/아니오가 갈리는 형태**로 적혀 있다.
>
> 준비: `npm run dev` → 설정 카드(Esc)에서 **음량 100%** 확인 → 헤드폰. 총 8분.
> 관측값은 이 문서의 "관측" 칸에 그대로 적는다. 실패·과다가 하나라도 있으면
> `docs/HANDOFF.md` 에 AUDIO 소유자 반환으로 등재한다.

## B. 청감 8항목

### B-1. 공간 대조 — 2분 (`?scene=` 프로브)

여섯 공간을 직접 걸어 비교한다. 각 주소로 열고 **클릭(마우스 잠금) → W 로 5초 걷기 → 한 번 멈춤**.

| # | 어디서 | 무엇을 듣는가 | 통과 기준 | 실패로 적을 소리 | 관측 |
|---|---|---|---|---|---|
| 1 | `?scene=lobby-night` → `?scene=corridor-night` 연속 | 같은 걸음의 꼬리 길이 | 로비에서 발소리 뒤에 **꼬리가 붙고**, 복도로 넘어가면 그 꼬리가 **눈에 띄게 짧아지면서 카펫으로 죽는다** | 두 공간의 꼬리 길이가 구분이 안 됨 | |
| 2 | `?scene=lobby-night` 로비 중앙에서 한 걸음 | 대리석 잔향의 길이 | 걸음 끝의 울림이 **1.5초 안에 끊긴다**(초를 센다) | 2초 넘게 끌면 "과다"라고 적는다 — RT60 을 더 내린다 | |
| 3 | `?scene=bathroom` → `?scene=rooftop-rain` | 잔향의 유무 | 욕실은 **금속성으로 링잉**하고, 옥상은 **잔향이 사실상 0**(비 소리만 남는다) | 옥상에서 울림이 들리면 실패 | |
| 4 | `?scene=corridor-night` 에서 제자리 회전 | 발소리 재질 | 대리석(로비)·카펫(복도)·타일(욕실)이 **서로 다른 소리**다. 카펫은 고역이 없고 짧다 | 세 재질이 같은 소리면 `player:footstep` 의 material 판별이 안 먹는 것 | |

### B-2. 본편 — 6분 (`http://127.0.0.1:5173/`)

| # | 어디서 | 무엇을 듣는가 | 통과 기준 | 실패로 적을 소리 | 관측 |
|---|---|---|---|---|---|
| 5 | 타이틀에서 **벨을 누르는 순간** | 게임의 첫 소리 | **놋쇠 누름종이 울린다**(두 번째 타격이 0.19초 뒤에 겹친다). 종소리 꼬리가 인트로의 물소리로 이어진다 | 무음이거나 딸깍 소리 하나 | |
| 6 | 인트로 0~30초, 가만히 둔다 | 물소리 밑의 저역 | 물소리·타건음 **밑으로** 아주 낮은 음(41Hz)이 4초에 걸쳐 스며들었다가 크로스헤어가 뜰 즈음 빠진다. **선율로 들리면 안 된다** — "음악이 나온다"가 아니라 "건물이 낮게 울린다"로 들려야 한다 | 악기·화음으로 인지되면 과다(톤 붕괴) · 아무것도 안 들리면 미달 | |
| 7 | 로비 진입 후 **라디오(오른쪽 사이드테이블) 쪽으로 걸어간다** | 디제틱 방송 | 멀리서 **웅얼거리는 사람 목소리**가 들리고, 다가가면 커진다. 말은 **알아들을 수 없다**. 정전기가 성기게 튄다 | 잡음만 나고 목소리 덩어리가 없으면 실패 · 말이 알아들리면 실패(자막이 진실원) | |
| 8 | 라디오 앞에서 **E — "주파수를 맞춘다"** | 상호작용 소리 | 다이얼 **디텍트 클릭 4번**과 동조가 올라오는 소리. 압지·팔걸이·연혁판도 각각 다른 소리가 난다 | 전부 같은 소리거나 무음 | |
| 9 | 다이치 심문 → 아무 진술에나 **거짓 지목 → 틀린 증거** | 소각과 침묵 | ①줄을 긋는 **한 획**과 그 아래로 꺼지는 저음 ②직후 3초 동안 환경음(룸톤·물·**라디오**)이 **한 걸음 물러난다**. 뚝 끊기지 않는다. 카메라 풀백과 같은 타이밍 | 딸깍 소리 하나로 끝나거나, 환경음이 그대로면 실패 | |
| 10 | 다이치 S4 에 **열쇠 걸이** 제시(정답) → 붕괴 | 음악 0 | 붕괴 연기 동안 비디제틱 층이 **사라지고 방의 소리만 남는다** | 저역이 계속 깔려 있으면 실패 | |
| 11 | 심문 종료 직후 **도일이 렌치를 들고 로비를 지나갈 때** | 1막의 유일한 음악적 표지 | 렌치 소리와 함께 **인트로에서 들었던 그 저음이 짧게 되돌아온다**(약 11초). 같은 음이라는 것이 인지돼야 한다 | 무관한 새 소리로 들리면 리트모티프 실패 | |
| 12 | 아무 때나 **Esc — 설정 카드** | 일시정지 감쇠 | 카드가 뜨는 동안 방 소리가 **뒤로 물러난다**(끊기지 않는다). 닫으면 돌아온다 | 음량이 그대로면 실패 | |

## D. 이 문서가 판정하지 않는 것 (정직 기록)

- **2·3막 공간의 실배치 청감**은 범위 밖이다(P2). B-1 은 `?scene=` 프로브라 공간의 **음향**만
  보고, 그 공간에 놓일 오브젝트·사건의 소리는 아직 없다.
- **1막에 비디제틱 BGM 은 넣지 않았다.** E7 §3 이 "이 게임에 비디제틱 BGM 은 엔딩 크레딧뿐"을
  불변으로 못 박고 있고, 심문의 침묵 연출(−6dB)은 음악이 깔리는 순간 판정 불가가 된다.
  6·11번이 그 자리를 대신한다 — 물의 리트모티프를 음정(41.2Hz)으로 진술해 3막 콘트라베이스가
  **새 곡이 아니라 그 음의 귀환**으로 들리게 하는 설계다. "1막이 심심하다"가 청감 결론이면
  그때 E7 개정을 걸어야 하는 사안이고, 오디오 소유자가 단독으로 뒤집을 계약이 아니다.
- **타이틀 화면에는 음악을 깔 수 없다.** 브라우저 자동재생 정책상 첫 제스처 전에는 어떤 소리도
  낼 수 없고(제스처 전 AudioContext 생성 = 콘솔 경고 = 루브릭 실격), 이 게임의 첫 제스처가
  곧 벨을 누르는 진행 입력이다. 그래서 타이틀의 자리는 음악이 아니라 벨 자신이다(5번).
- **시계추·괘종은 넣지 않았다.** 로비에 시계 소품이 없어 물질 원점 없는 소리가 된다
  (E7 불변 금지 3종). PROPS 반환으로 `docs/HANDOFF.md` 에 등재했다.
