# 오디오 청감 확인 — 헤드폰 12분 (N7 · J6)

> 기계가 못 보는 유일한 축이다. 헤드리스 프로브는 **RMS 만** 본다 — "무섭게 들리는가"는
> 여기서만 판정된다. 3차 판정(`docs/reviews/fable-experience-2026-08-09-r3.md` §6-1)은
> **J6 7점이 이 시트의 통과를 전제로 매겨진 점수**라고 명시했다. 이 시트가 비어 있으면
> J6의 절반은 아직 아무도 듣지 않은 것이다.
>
> 항목은 전부 "자연스러운가" 같은 감상이 아니라 **한 번 듣고 예/아니오가 갈리는 형태**다.
> **번호는 고정 ID**다(다른 문서가 번호로 참조한다). 아래는 **번호순이 아니라 걷는 순서**로
> 배열돼 있다 — 위에서 아래로 그냥 따라가면 공간을 되돌아가지 않는다.

**준비 (2분)**
1. `npm run dev` → <http://127.0.0.1:5173/> (배포본 <https://bluetop1102.github.io/virgil-1947/> 도 같다)
2. **헤드폰 착용** — 41Hz 저역은 노트북 스피커에서 재생되지 않는다. 노트북 스피커는 §5에서 한 번만 쓴다.
3. Esc → 설정에서 **음량 100%** 확인 → 카드를 닫는다.
4. **새 회차**로 시작한다(타이틀에 「체크인」 명패가 떠 있는 상태).

**총 12분** — §1~§5가 본편 1회차(10분), §6이 공간 프로브(2분)다.
관측값은 각 표의 "관측" 칸에 그대로 적고, 다 끝나면 **§C 판정 기록**을 채운다.

## D. 이 문서가 판정하지 않는 것 (정직 기록)

- **2·3막 공간의 실배치 청감**은 범위 밖이다(P2). §6은 `?scene=` 프로브라 공간의 **음향**만 보고,
  그 공간에 놓일 오브젝트·사건의 소리는 아직 없다.
- **1막에 비디제틱 BGM 은 여전히 0이다.** E7 §3 이 "비디제틱 BGM 은 엔딩 크레딧뿐"을 불변으로
  못 박고 있다. 늘어난 두 층은 계약 **안쪽**이다 — ①심문 긴장층은 곡이 아니라 물의
  리트모티프(41.2Hz)를 늘인 저역 이벤트이고(15~17), ②라디오 음악은 로비 소품에서 나오는
  디제틱 음원이다(18~19). 이 두 층이 소각의 침묵을 덮으면 계약이 깨진 것이고, 9번이 그것을 본다.
- **타이틀 화면에는 음악을 깔 수 없다.** 브라우저 자동재생 정책상 첫 제스처 전에는 어떤 소리도
  낼 수 없고(제스처 전 AudioContext 생성 = 콘솔 경고 = 루브릭 실격), 이 게임의 첫 제스처가
  곧 벨을 누르는 진행 입력이다. 그래서 타이틀의 자리는 음악이 아니라 벨 자신이다(5번).
- **시계추·괘종은 넣지 않았다.** 로비에 시계 소품이 없어 물질 원점 없는 소리가 된다
  (E7 불변 금지 3종). PROPS 반환으로 `docs/HANDOFF.md` 에 등재했다.
