# 오디오 청감 확인 — 헤드폰 12분 (N7 · J6)

> 기계가 못 보는 유일한 축이다. 리뷰(`docs/reviews/fable-experience-2026-08-08.md` N7)는 2회 모두
> **판정 보류**였고 — 헤드리스라 소리를 못 들었다 — 사용자 실플레이 피드백("효과음이랑 BGM이
> 적당하지 않은 것 같다")도 여기에 걸렸다. 2026-08-09 JUDGE 판정은 J6 을 **4점(바닥 위반)** 으로
> 찍었고, 그 근거 3건 중 2건(음악층 실효 0 · 심문 역전)은 이번에 기계로 닫았다. **남은 것은 톤이다 —
> 기계는 RMS 만 본다. "무섭게 들리는가"는 여기서만 판정된다.**
>
> 아래는 **코드로는 판정이 불가능한 것만** 남긴 목록이고, 각 항목은 "자연스러운가" 같은 감상이
> 아니라 **한 번 듣고 예/아니오가 갈리는 형태**로 적혀 있다.
>
> 준비: `npm run dev` → 설정 카드(Esc)에서 **음량 100%** 확인 → **헤드폰**(41Hz 저역은 노트북
> 스피커에서 재생되지 않는다). 총 12분. 관측값은 각 표의 "관측" 칸에 그대로 적는다.
> 실패·과다가 하나라도 있으면 `docs/HANDOFF.md` 에 AUDIO 소유자 반환으로 등재한다.

## B-1. 공간 대조 — 2분 (`?scene=` 프로브)

여섯 공간을 직접 걸어 비교한다. 각 주소로 열고 **클릭(마우스 잠금) → W 로 5초 걷기 → 한 번 멈춤**.

| # | 어디서 | 무엇을 듣는가 | 통과 기준 | 실패로 적을 소리 | 관측 |
|---|---|---|---|---|---|
| 1 | `?scene=lobby-night` → `?scene=corridor-night` 연속 | 같은 걸음의 꼬리 길이 | 로비에서 발소리 뒤에 **꼬리가 붙고**, 복도로 넘어가면 그 꼬리가 **눈에 띄게 짧아지면서 카펫으로 죽는다** | 두 공간의 꼬리 길이가 구분이 안 됨 | |
| 2 | `?scene=lobby-night` 로비 중앙에서 한 걸음 | 대리석 잔향의 길이 | 걸음 끝의 울림이 **1.5초 안에 끊긴다**(초를 센다) | 2초 넘게 끌면 "과다"라고 적는다 — RT60 을 더 내린다 | |
| 3 | `?scene=bathroom` → `?scene=rooftop-rain` | 잔향의 유무 | 욕실은 **금속성으로 링잉**하고, 옥상은 **잔향이 사실상 0**(비 소리만 남는다) | 옥상에서 울림이 들리면 실패 | |
| 4 | `?scene=corridor-night` 에서 제자리 회전 | 발소리 재질 | 대리석(로비)·카펫(복도)·타일(욕실)이 **서로 다른 소리**다. 카펫은 고역이 없고 짧다 | 세 재질이 같은 소리면 `player:footstep` 의 material 판별이 안 먹는 것 | |

## B-3. 이번 라운드 신설분 — 4분 (J6 · judge-plan §5)

기계가 "역전이 해소됐다"까지만 증명한 자리다. **그 소리가 무엇으로 들리는지는 여기서 갈린다.**

|---|---|---|---|---|---|
| 13 | **첫 12초 몽타주** — 벨을 누르고 눈을 감고 듣는다 | 벨 → 물소리 → 드론 → 타자기가 이어지는가 | 네 소리가 **차례로 겹치며 넘어간다**. 벨 꼬리가 끝나기 전에 물이 들어오고, 물 밑으로 드론이 스며든 뒤에 타건이 시작된다 | 소리 사이에 **빈 구멍**이 생기거나, 넷이 동시에 시작해 뭉치면 실패 | |

## D. 이 문서가 판정하지 않는 것 (정직 기록)

- **2·3막 공간의 실배치 청감**은 범위 밖이다(P2). B-1 은 `?scene=` 프로브라 공간의 **음향**만
  보고, 그 공간에 놓일 오브젝트·사건의 소리는 아직 없다.
- **1막에 비디제틱 BGM 은 여전히 0이다.** E7 §3 이 "이 게임에 비디제틱 BGM 은 엔딩 크레딧뿐"을
  불변으로 못 박고 있다. 이번에 늘어난 두 층은 계약 **안쪽**이다 — ①심문 긴장층은 곡이 아니라
  물의 리트모티프(41.2Hz)를 늘인 저역 이벤트이고(15~17번), ②라디오 음악은 로비 소품에서
  나오는 디제틱 음원이다(18~19번). 심문의 침묵 연출(−6dB)이 판정 가능한 상태로 남아 있는지는
  9번이 본다 — 이 두 층이 침묵을 덮으면 계약이 깨진 것이다.
- **타이틀 화면에는 음악을 깔 수 없다.** 브라우저 자동재생 정책상 첫 제스처 전에는 어떤 소리도
  낼 수 없고(제스처 전 AudioContext 생성 = 콘솔 경고 = 루브릭 실격), 이 게임의 첫 제스처가
  곧 벨을 누르는 진행 입력이다. 그래서 타이틀의 자리는 음악이 아니라 벨 자신이다(5번).
- **시계추·괘종은 넣지 않았다.** 로비에 시계 소품이 없어 물질 원점 없는 소리가 된다
