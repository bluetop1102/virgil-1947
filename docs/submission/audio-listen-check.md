# 오디오 청감 확인 — 사람 귀로만 판정되는 5항목 (N7)

> 리뷰(`docs/reviews/fable-experience-2026-08-08.md` N7)는 **판정 보류**다 — 헤드리스라
> 소리를 못 들었다. 기계 게이트(`node tools/test-audio.mjs --roomtone`)는 통과 중이므로
> 남은 것은 청감뿐이다. 아래 5항목은 코드 점검으로는 판정이 불가능한 것만 남긴 것이고,
> **헤드폰**으로 한 번 완주하며 확인한다. 관측값은 이 문서에 그대로 적는다.
>
> 실행: `npm run dev` → `http://127.0.0.1:5173/` → 벨 → 인트로 → 로비.
> 설정 카드(Esc)의 **음량 100%** 확인부터 하고 시작한다.

## 코드 점검 결과 (청감 전에 확정된 것)

- **공간별 리버브는 실재한다.** `audio/ir.js`가 6종 IR을 절차 생성하고
  `audio/engine.js:setRoom()`이 `room:changed`로 컨볼버를 교차 페이드한다.
  실측 RT60(`test-audio.mjs`): 로비 2.38s · 복도 1.50s · 객실 0.40s · 욕실 1.03s ·
  옥상 0.12s · 엘리베이터 0.34s. **E7 §3 사양과 어긋나는 값이 둘 있다** —
  로비(사양 1.6s / 실측 2.38s) · 복도(사양 0.9s / 실측 1.50s). 둘 다 사양보다 젖어 있다.
  숫자로는 판정할 수 없어 아래 1번에 청감 항목으로 올린다.
- **1막에서는 로비 하나만 들린다.** `room:changed`를 발화하는 레벨이 `world/lobby.js`
  단 하나다(`room:changed {room:'lobby'}`). 공간 간 **대조**는 2·3막 공간이 들어오는
  P2 범위이며, 지금 리허설로 확인 가능한 것은 "로비의 성격이 맞는가"까지다.
- **침묵 연출은 E7 §3 사양대로 배선돼 있다.** 오답(LIE·correct=false) →
  `roomtoneDip(3, -6)`으로 룸톤·물소리 버스만 3초 −6dB, 붕괴(`perf:state breaking`) →
  `_setBreaking`으로 음악 버스 0. **비디제틱 BGM은 엔딩뿐**이라는 계약도 유지된다.
- 미사용 API 1건(정리 대상 아님, 소유자 판단용): `audio/engine.js:silence()`는
  마스터를 완전히 끄는 더 강한 도구인데 호출부가 없다. E7 §3이 요구하는 것은 −6dB 딥이라
  현행이 사양 충족이고, `silence()`는 남은 여지다.

## 청감 5항목

| # | 무엇을 | 어떻게 재현하는가 | 무엇이면 통과인가 | 관측 |
|---|---|---|---|---|
| 1 | 로비의 젖음 정도 | 로비 중앙에서 걸어보고, 데스크 앞에서 다이치 대사를 듣는다 | 대리석 홀로 들리되 **대사의 자음이 잔향에 먹히지 않는다.** 먹히면 RT60 2.38s가 과하다는 뜻이므로 이 칸에 "과다"라고 적는다 | |
| 2 | 오답 뒤의 −6dB 침묵 | 심문에서 아무 진술에나 **거짓 지목 → 틀린 증거** 제시 | 판정 직후 3초 동안 환경음이 **물러난다**. 뚝 끊기는 게 아니라 한 걸음 뒤로 가는 느낌. 카메라 풀백과 같은 타이밍에 온다 | |
| 3 | 붕괴 순간의 음악 0 | 다이치 S4에 **열쇠 걸이**를 제시(정답) | 붕괴 연기 동안 비디제틱 층이 사라지고 방의 소리만 남는다 | |
| 4 | 발소리 재질 | 로비 대리석 → 소파 쪽 러그 위를 걸어본다 | 두 재질이 **다른 소리**다. 같으면 `player:footstep`의 material 판별이 안 먹는 것 | |
| 5 | 물의 리트모티프 | 인트로 0~4초(수압 파열음)와 로비 라디오 앞의 저주파를 이어 듣는다 | 같은 저주파 모티프의 변주로 들린다. 무관한 두 소리로 들리면 실패 | |
