## 1. 제목

**VIRGIL — 1947 · Room 942**

## 2. 한 줄 소개

1947년 로스앤젤레스, 9일간 실종된 투숙객의 방에서 시작하는 1인칭 수사물.
**틀리게 내민 증거는 영원히 사라진다.**

## 3. 이것이 어떤 게임인가 (3문단 이내)

- **무엇을 하는가**: LAPD 형사가 되어 호텔 버질에서 아이리스 밴스(22)의 실종을 수사한다.
  공간을 뒤져 증거를 모으고, 네 인물을 심문하고, 마지막에 증거판 위에서 범인을 지목한다.
- **왜 다른가**: 심문의 세 선택(진실·의심·거짓) 중 "거짓"을 고르면 수사노트에서 증거를
  직접 지목해야 하고, **틀리면 그 진술의 정보가 이 회차에서 영구히 사라진다**(소각).
  세이브·로드로 되돌릴 수 없다 — 체크포인트는 막 경계 자동 저장 1슬롯뿐이고, 복원해도
  소각은 유지된다. 화면 어디에도 남은 기회·정답률·체크 표시가 없다.
- **그래서 무엇이 남는가**: 증거를 다 잃은 채 도달하는 미제 엔딩도 **정식 엔딩**이다.
  실패한 수사는 호텔의 괴담 한 줄로 세계에 기록된다.

## 4. 게임 방법

### 목표
아이리스 밴스에게 무슨 일이 일어났는지 밝히고, 3막 옥상에서 증거판의 링크 3개를 성립시켜
범인을 지목한다.

### 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 | 포인터 잠금(시작) |
| **W A S D** | 이동 |
| 마우스 | 시선 |
| **E** | 상호작용 — 관찰·수집·심문 개시 |
| **Tab** | 수사노트 열기/닫기 |
| **Esc** | 일시정지 + 설정 카드 |

*(구현 확정 시 재확인: 심문 3선택 입력 키 · 증거 지목 입력 · 사진 스크럽 조작 —
`docs/design/E8-ui.md` §1·§2)*

### 진행 구조

| 막 | 공간 | 핵심 |
|---|---|---|
| I | 로비·프런트·엘리베이터 | 숙박부 확인, 야간 프런트 다이치 심문 |
| II | 9층 복도·942호·944호 | 현장 수색, 하우스키퍼 루이즈 / 투숙객 프라이스 심문 |
| III | 옥상·물탱크 | 발견, 증거판 최종 지목 |

플레이 타임 목표 **40~60분**.

### 종료 조건
증거판의 조서에 **서명**하면 지목이 종결된다. 그 시점에 성립한 링크 수가 엔딩을 정한다 —
3개 완전 / 2개 부분 / 1개 이하 미제. 링크 3개가 성립하는 순간은 서명 없이 자동 종결된다.

## 5. 실행 방법

1. 아래 플레이 링크를 클릭한다. 설치·계정·API 키가 필요 없다.
2. 로딩 화면의 허구 고지문이 끝나면 **"프런트 벨을 누르십시오"** 가 뜬다. 아무 키나 클릭 —
   이 첫 입력이 브라우저의 소리·마우스 잠금을 여는 제스처다.
3. 권장 환경: 크로미움 계열 최신 브라우저 · WebGL2 · 디스크리트 GPU 권장.
   사양이 낮으면 **Esc → 설정 → 품질 프리셋**을 `medium` 또는 `low` 로 내린다(리로드된다).

소스에서 직접 실행:
```bash
npm install
npm run dev      # http://127.0.0.1:5173
```
