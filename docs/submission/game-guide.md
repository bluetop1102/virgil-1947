## 2. 이것이 어떤 게임인가

**무엇을 하는가.** LAPD 형사가 되어 호텔 버질에서 아이리스 밴스(22)의 실종을 수사한다. 공간을
뒤져 증거를 모으고, 호텔 사람들을 심문하고, 마지막에 증거판 위에서 범인을 지목한다.

**왜 다른가 — 비가역.** 심문의 세 선택(진실·의심·거짓) 중 "거짓"을 고르면 수사노트를 열어
증거를 직접 지목해야 한다. **틀리면 그 진술이 담고 있던 정보가 이 회차에서 영구히 사라진다**
(소각). 되돌릴 방법이 없다 — **이 제출본에는 세이브·로드가 없다.** 브라우저에 남는 것은
설정값뿐이고, 새로고침하면 새 회차다. 화면 어디에도 남은 기회·정답률·체크 표시가 없다.
게임이 알려주는 것은 증거를 내밀기 직전에 뜨는 경고 한 줄뿐이다: **"제시한 증거는 회수되지
않는다. 닫힌 진술은 다시 열리지 않는다. 수사는 계속된다."**

**그래서 무엇이 남는가.** 증거를 다 잃은 채 도달하는 미제 엔딩도 **정식 엔딩**이다. 실패한
수사는 호텔의 괴담 한 줄로 세계에 기록된다 — "버질은 계속 영업했다. 9층 이야기가 하나 늘었다."

**아트 디렉션 — 마리오네트 노어.** 인물은 사실적 인체가 아니라 도자기 얼굴에 볼 관절을 가진
**나무 마리오네트**다. 표정이 없기 때문에 거짓말의 신호(텔)가 전부 몸으로 나온다 — 반 발
물러서는 어깨, 카운터 선에서 멈추는 오른손, 문장 끝에 떨어지는 음량. 플레이어는 표정을 읽는
대신 **몸을 읽는다.**

*(스크린샷 ②: `frames/sub-11-s1-choice.jpg` — 심문 중 다이치. 도자기 얼굴·볼 관절의 마리오네트가
데스크 너머에 앉아 있고, 카운터 위에 찢은 종이 쪽지로 `1. 진실  2. 의심  3. 거짓`이 놓여 있다)*

## 3. 이번 제출본의 범위 (먼저 밝힌다)

**제출본은 1막 수직 슬라이스다.** 3막 전체의 사건·대사·증거·엔딩은 설계와 데이터가 완성돼 있고
(`docs/STORY.md` · `docs/design/case-graph.json` — 증거 14종·진술 14건·엔딩 3종), 그중
**1막(로비·프런트)이 플레이 가능한 레벨로 구현돼 있다.** 2·3막 공간은 이번 범위 밖이다.

| 막 | 공간 | 상태 |
|---|---|---|
| **I** | 로비·프런트·엘리베이터 | **플레이 가능** — 숙박부 등 증거 4종, 야간 프런트 다이치 심문(진술 5건), 괴담 3건 |
| II | 9층 복도·942호·944호 | 데이터 완성 · 레벨 미구현 |
| III | 옥상·물탱크·증거판 | 데이터 완성 · 레벨 미구현 |

플레이는 다이치 심문이 끝나고 엘리베이터를 타면 2막으로 전환되며 끝난다. 설계상 전 3막
플레이 타임 목표는 40~60분이고(`docs/ARCHITECTURE.md` §0), 이번 제출본은 그 첫 구간이다.
아래 §4의 목표·종료 조건은 **1막 기준**으로 적고, 전체 설계는 §4.4에 따로 적는다.

## 4. 게임 방법

### 4.1 목표

야간 프런트 **마를로 다이치**에게서 아이리스 밴스가 사라진 밤에 무슨 일이 있었는지 알아낸다.
그러려면 먼저 로비에서 그를 반박할 재료를 모아야 한다 — 숙박부, 열쇠 걸이, 위스키 플라스크,
수압 민원 장부. **증거 없이 거짓을 지목하면 진술은 소각된다.**

게임은 목표를 목록으로 주지 않는다. 조작을 넘겨받는 순간 형사의 독백 한 줄이 첫 목적지를
알려준다 — *"프런트부터다. 숙박부를 봐야겠다."*

### 4.2 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 | 포인터 잠금(시작) · 시선 |
| **W A S D** | 이동 |
| **E** | 상호작용 — 관찰·수집·심문 개시·라디오 다이얼 |
| **Tab** | 수사노트 열기/닫기 |
| **Esc** | 일시정지 + 설정 카드 (열려 있는 것이 있으면 그것부터 닫는다) |

게임을 넘겨받는 순간 화면 아래에 **손글씨 종이 카드**가 3.5초간 놓이고, 위 네 줄이 그대로
적혀 있다(`이동 W A S D · 조사 E · 수첩 Tab · 카드 Esc`). 놓쳐도 **Esc → 설정 카드**의 조작
행에 같은 내용이 상시 남아 있다.

심문에 들어가면 두 가지가 추가된다.

| 입력 | 동작 |
|---|---|
| **1 · 2 · 3** (또는 쪽지를 마우스로 클릭) | 진술에 대한 판단 — 진실 / 의심 / 거짓 |
| **← → ↑ ↓** 이동 · **Enter** 결정 · **Esc** 취소 (또는 증거를 마우스로 클릭) | "거짓"을 골랐을 때 수사노트에서 증거 지목 |

**모든 선택은 키보드와 마우스 양쪽으로 된다.** 심문 쪽지도, 증거 지목도 클릭이 그대로 먹는다.

*(스크린샷 ③: `frames/sub-30-picker.jpg` — 증거 지목 화면. LAPD 실종 서식에 MISSING PERSON
스탬프와 커피 얼룩, 형사가 펜으로 두른 붉은 원, 그 위에 비가역 경고 스트립)*

### 4.3 플레이 흐름 (1막)

1. **체크인** — 타이틀에서 프런트 벨을 누른다. 이 첫 입력이 브라우저의 소리와 마우스 잠금을 연다.
2. **인트로 30초** — 물소리와 타자기 자막으로 사건이 열리고, 로비를 1인칭으로 훑는 카메라가
   형사의 배지를 데스크에 내려놓으며 조작을 넘긴다.
3. **수사** — 로비를 돌며 **E**로 관찰·수집한다. 증거를 집으면 종이 슬립이 뜨고 **Tab** 수사노트에
   기록된다. 라디오 앞에서 **E**를 누르면 주파수가 바뀌고, 어느 자리에서는 호텔 괴담 방송이 나온다.
4. **심문** — 다이치에게 **E**. 진술마다 카메라가 다르게 붙고(미디엄 → 푸시인 → 풀백), 쪽지로
   세 선택이 제시된다. **거짓**을 고르면 수사노트가 열리고 증거를 지목한다.
   - 맞으면 상대가 물러서고 새 진술이 열린다.
   - 틀리면 취소선이 그어지고 **그 진술은 닫힌다.** 카메라가 반 발 물러나고 방의 소리가 함께 가라앉는다.
5. **이양** — 심문이 끝나면 엘리베이터가 열린다. 타면 2막으로 넘어가며 이번 제출본의 플레이가 끝난다.

**분량**: 완주 봇이 최단 경로로(자막 대기를 건너뛰고) 1분 4초에 2막 전환에 닿는다. 사람이
자막을 읽고 로비를 둘러보면 그보다 여러 배 길다.

### 4.4 종료 조건

**1막(제출본)**: 다이치의 진술 5건을 모두 처리하면 심문이 종결되고, 그 뒤 엘리베이터에 **E**를
누르면 2막으로 전환되며 플레이가 끝난다. 심문은 증거를 다 모으지 않아도 시작할 수 있지만,
**내밀 증거가 없으면 "거짓"을 골라도 지목이 성립하지 않는다** — 로비를 먼저 뒤지는 것이 전제다.
심문 결과에 따라 다음 막에 넘어가는 상태가 갈린다: 열쇠 건을 인정받으면 재심문 경로가 열리고,
소각으로 닫힌 진술은 이후에도 열리지 않는다.

**전체 설계(3막)**: 3막 옥상의 증거판에서 **링크 3개**를 건다. 링크 하나는 *증거 2개 + 주장 1개*로
성립하고, 수집한 증거로만 걸 수 있다. 조서에 **서명**하면 지목이 종결되고, 그 시점에 성립한
링크 수가 엔딩을 정한다.

| 성립 링크 | 엔딩 | 마지막 컷 |
|---|---|---|
| 3 | **완전** — 도일 체포, 넬 밴스 사건 재수사 개시 | 물탱크의 물이 빠지는 소리 |
| 2 | **부분** — 구금 48시간, 소유주 변호사가 온다 | 프런트에 걸린 942호 열쇠 |
| 1 이하 | **미제** — 사건 종결 | 새 손님이 942호 열쇠를 받아 간다 |

링크 3개가 성립하는 순간은 서명 없이 자동 종결된다. **미제는 실패 화면이 아니라 정식 엔딩이다.**

## 5. 실행 방법

### 5.1 브라우저에서 (심사용 권장 경로)

1. **<https://bluetop1102.github.io/virgil-1947/> 를 클릭한다.** 설치·계정·API 키가 필요 없다.
2. 로딩 화면의 허구 고지문이 끝나면 타이틀에 프런트 벨과 **「체크인」** 명패가 뜬다.
   **명패를 누르거나 화면 아무 곳이나 클릭한다** — 이 첫 입력이 소리와 마우스 잠금을 여는 제스처다.
3. 이후는 §4.2의 조작 그대로. 클릭으로 마우스가 잠기고, **Esc**로 언제든 풀린다.

**권장 환경**: 크로미움 계열 최신 브라우저 · WebGL2 · 헤드폰(저역 41Hz가 노트북 스피커에서는
재생되지 않는다). 사양이 낮으면 **Esc → 설정 → 품질**을 `medium` 또는 `low`로 내린다(리로드된다).
주소에 `?q=low`를 붙여 처음부터 낮은 품질로 열 수도 있다.

**진행은 저장되지 않는다.** 탭을 닫거나 새로고침하면 처음부터다(품질·음량 등 설정만 남는다).
한 번에 끝까지 앉아서 하는 분량이라 그렇게 설계했고, 소각의 비가역도 같은 이유로 성립한다.

### 5.2 소스에서 직접

```bash
git clone https://github.com/bluetop1102/virgil-1947
cd virgil-1947 && npm install
npm run dev            # http://127.0.0.1:5173
```

정적 빌드는 `npm run build:pages`다(상대 경로 빌드 — 서브패스 배포용).
